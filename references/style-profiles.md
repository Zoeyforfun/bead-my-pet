# 拼豆风格档案

本文件定义可扩展的风格档案。新增风格时只增加一个独立档案，不改变核心输出契约、网格数据结构和渲染链路。

## 档案字段

每个风格必须说明：

- `style_id`：稳定、简短的英文标识；
- 中文名称与一句话效果；
- 适合的输入特征；
- 不适合或需要较大网格的情况；
- 必须保留的身份与构图信息；
- 允许的形状、比例和纹理调整；
- 调色原则、起始色数和禁用色偏；
- 杂色与小色块处理；
- 建议网格范围；
- 风格专属验收条件。

风格只改变主稿和颜色归纳方式。所有风格最终都必须从同一份 `pattern.json` 与 `counts.csv` 生成标准图纸、纯白中性底的提炼成品图和透明背景的颂拼豆导入图。

## realistic-reduced｜写实提炼

**效果**：尽量保持照片中的真实轮廓、五官、花纹、材质和主色，在不损害身份特征的前提下减少杂色与制作难度。

**优先推荐**：

- 主体清晰、光线自然、脸部或关键结构可辨；
- 用户重视“像本人 / 像这一只”，用于纪念、肖像或高还原制作；
- 主体具有独特眼色、毛色、斑纹、饰品或轮廓。

**谨慎推荐**：

- 强逆光、彩色环境光、严重压缩噪点或毛发极其细碎；
- 网格过小却需要保留全身、多个道具或复杂背景。

**主稿处理**：

- 保持真实脸型、眼睛比例、鼻嘴形状、姿势、花纹和主色关系；
- 去除无关背景；与主体互动且有辨识作用的配饰或道具按用户选择保留；
- 不默认动漫化、磨皮、夸张大眼或重新设计；
- 毛发、反光和材质纹理允许归纳成少量连续色区，不逐根复刻。

**颜色与杂色**：

- 先保护眼睛、鼻口、耳内、主花纹、轮廓转折和高识别度饰品；
- 对受光噪声、压缩噪声、毛发抖动造成的杂色区域做区域化归并：保留能说明体积、花纹或材质的少量代表色，其余并入面积最大的邻近主色；
- 大面积区域优先形成单一主色或“主色 + 1–2 个明暗辅助色”，避免多种近似色交错；
- 不把灰白等中性色错误映射为粉、绿、紫、黄等无来源色点；
- 约 40 格以内从 8–14 色尝试，41–64 格从 10–18 色尝试，更大网格可按身份信息增加，但不为模拟照片渐变而增色。

**验收**：在纯图案预览中仍能辨认同一主体；杂色减少后，关键花纹、五官和体积转折没有被抹平。

## bright-anime｜动漫提炼

**效果**：先提炼主体和叙事道具的图形、色块与遮挡关系，再使用清晰描边和克制、清爽的接近色重构为拼豆友好的动漫插画。优先增强色块区分度，不默认提高全图亮度。

**优先推荐**：

- 照片有明确姿势、表情、配饰、玩具或互动关系；
- 背景杂乱，但主体与关键道具容易分离；
- 用户重视可爱、醒目、装饰性和社交分享效果；
- 原图色调偏灰、偏暗，希望成品更活泼。

**谨慎推荐**：

- 用户要求严格照片比例、严谨毛色还原或纪念级写实；
- 关键身份仅依赖非常细微的毛发渐变，且网格较小。

**主稿处理**：

- 保留主体数量、姿势、朝向、外轮廓、品种特征、关键花纹、配饰和道具的相对位置；
- 删除无关环境，将主体与关键道具重组为清晰、紧凑的前景构图；
- 增加连续深色外描边，并在五官、耳内、爪部、配饰和道具交界处保留必要内部结构线；
- 允许轻微增强眼睛、表情和轮廓可读性，但不得替换为通用动漫脸、改变主体身份或凭空增加花纹；
- 毛发和复杂材质转成连续块面，不在主稿中生成网格、豆子、坐标、色号或统计文字。

**颜色抽象**：

- 先从原图提取主色、辅色和高识别度局部色；默认保持原图整体明度，只在相邻颜色难以区分时做局部、轻量的明度或饱和度调整；
- 保持色相关系和冷暖角色，不做全局增亮或高饱和滤镜；暗黄仍保持棕黄体系，灰蓝仍保持灰蓝体系，不得把灰猫改成粉猫、把棕色饰品改成绿色等无依据换色；
- 白色、米白、浅灰等身份花纹先建立保护蒙版，禁止因白底抠除、量化或提亮而消失；白色主体与背景接近时，主稿改用中等明度的临时对比底色，最终导入图再恢复透明背景；
- 白色/浅色花纹与相邻主色之间必须保留连续的深色或中间深度边界；边界放在主色一侧，不能吞掉窄额纹、眼间白斑、吻部或胸前白毛；
- 阴影优先使用主色的较深接近色，不用脏黑覆盖大面积主体；高光使用较浅接近色，但不得造成过曝感；
- 整体形成清爽、清晰、对比适中的调色；眼色、鼻色、身份花纹等高识别度颜色必须可追溯到原图；
- 单主体约 56–90 格可从 12–22 色尝试；全身加道具约 80–120 格可从 16–28 色尝试。减少颜色时先合并作用重复的阴影和高光色。

**描边控制**：

- 外轮廓应连续，但宽度不得吞掉耳尖、眼睛、鼻口或小型配饰；
- 接壤物体用必要分隔线保持可读性；
- 阴影边界不全部描黑，避免画面僵硬和黑色占比过高。

**验收**：一眼可辨为原主体和原构图；整体明度接近原图、颜色清爽但不过曝；白色和浅色身份区域完整且与相邻主色有连续边界；无无依据换色；描边完整、块面连续，放大后没有大量孤立色点。

## 风格推荐排序

先分析输入，再给出带理由的优先级。推荐不是替用户决定：用户已指定风格时直接执行；未指定时列出可用风格及排序，等待用户选择。

评分维度：

1. **身份还原需求**：独特五官和花纹越重要，`realistic-reduced` 越靠前；
2. **构图叙事性**：配饰、道具、姿势和互动越突出，`bright-anime` 越靠前；
3. **画面噪声**：背景杂乱、光线偏暗或毛发碎色很多时，动漫模式通常更稳定；写实模式仍可通过区域化降杂色处理；
4. **目标网格**：小网格优先选择能把信息压缩成清晰块面的风格；复杂全身场景应建议提高网格；
5. **用途**：纪念肖像优先写实提炼，装饰、礼物、头像和社交分享优先动漫提炼。

推荐输出示例：

- `1. 写实提炼`：脸部和眼色清晰，独特特征多，最有利于保持“像这一只”。
- `2. 动漫提炼`：原图道具和姿势有趣，若希望更活泼醒目可选择。

用户选择后锁定 `style_id`，后续多尺寸版本沿用同一风格；只有用户明确要求时才为同一照片分别制作多种风格。

## 新增风格规则

新增风格时：

1. 按本文件的档案字段增加独立小节；
2. 将新风格加入推荐排序候选；
3. 说明它相对现有风格新增的视觉价值，不复制已有模式；
4. 不修改三类必交付产物和数据一致性要求；
5. 为该风格增加至少一个正向适用场景、一个不适用场景和可检查的验收条件。
